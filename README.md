# Bank Dashboard - تحليل كشوفات الحسابات البنكية

تقرير مفصل وشامل لتحليل كشوفات الحسابات البنكية (الراجحي + الأهلي السعودي).

## الملفات

- `public/index.html` — صفحة التقرير الرئيسية
- `render.yaml` — إعدادات النشر على Render

## طريقة النشر على Render

1. ارفع هذا المجلد كـ Repository جديد على GitHub
2. ادخل على [render.com](https://render.com) وسجل دخول
3. اضغط **New** → **Static Site**
4. اربط حساب GitHub واختر الـ Repository
5. الإعدادات تلقائية من ملف `render.yaml`
6. اضغط **Deploy** وانتظر الرابط ✅
